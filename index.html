LinhScript (đuôi file .hql) là ngôn ngữ thông dịch do Hà Quang Linh phát triển. Cú pháp dễ học như Python/JS, tích hợp sẵn 28 thư viện lõi từ Web Server, Database, Game 2D đến xuất Excel/PDF.

Tải LinhScript 1.0.0 (Windows)
File: LinhScript-Setup-1.0.0.exe (~34.5 MB) • Đã kèm sẵn môi trường chạy
hello.hql 
// Chương trình LinhScript đầu tiên
use hql.math;
use hql.time;

var ten = "Linh";
print("Xin chào " + ten + "!");
print("Hôm nay là: " + format(now(), "dd/MM/yyyy"));

// Vòng lặp & tính toán gọn nhẹ
for i in 1 .. 5 {
    print("Giai thừa " + i + " = " + factorial(i));
}

Cài đặt & Bắt đầu trong 1 phút

Bộ cài đặt tự động cấu hình biến môi trường hệ thống (PATH) tương tự như Python.

1

Tải bộ cài đặt

Nhấn nút Tải LinhScript 1.0.0 ở phía trên để tải tệp LinhScript-Setup-1.0.0.exe về máy tính Windows của bạn.

2

Chạy trình cài đặt

Mở tệp vừa tải, tích chọn "Add LinhScript to PATH (Khuyên dùng)" và nhấn Next → Install. Chương trình sẽ tự cài vào AppData\Local\Programs\LinhScript.

3

Chạy mã nguồn .hql

Mở Terminal / CMD ở thư mục bất kỳ và gõ lệnh:

LinhScript hello.hql

Tích hợp sẵn 28 thư viện lõi

Chỉ cần gọi use hql.<tên>; là dùng được ngay mà không cần trình quản lý gói ngoài.

Web Server & HQLSP

hql.web, hql.net, hql.socket — Tạo web server, trang động .hqlsp, WebSocket và gọi API.

Cơ sở dữ liệu

hql.database, hql.env — Hỗ trợ SQL Server, MySQL, PostgreSQL, SQLite kèm Connection Pool.

Game 2D & Đồ họa

hql.game, hql.multiplayer — Vòng lặp 60FPS, sprite, bản đồ isometric, âm thanh và mạng đa người chơi.

Văn phòng & Báo cáo

hql.export, hql.chart, hql.mail — Xuất file Excel, Word, PDF có màu sắc, vẽ biểu đồ và gửi email SMTP.

Giao diện & Tự động hóa

hql.ui, hql.app, hql.pc — Tạo cửa sổ Swing, đóng gói web thành app Chromium, điều khiển phím/chuột.

Toán học & Bảo mật

hql.math, hql.crypto, hql.schedule — Thống kê, ma trận, mã hóa AES/RSA và lập lịch chạy tác vụ Cron.

LinhScript (HQL) — Phát triển bởi Hà Quang Linh.
