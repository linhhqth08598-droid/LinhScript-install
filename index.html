Cài đặt & Bắt đầu trong 1 phút

Bộ cài đặt tự động cấu hình biến môi trường hệ thống (PATH) tương tự như Python.

1

Tải bộ cài đặt

Nhấn nút Tải LinhScript 1.0.0 ở phía trên để tải tệp LinhScript-Setup-1.0.0.exe về máy tính Windows của bạn.

2

Chạy trình cài đặt

Mở tệp vừa tải, tích chọn "Add LinhScript to PATH (Khuyên dùng)" và nhấn Next → Install. Chương trình sẽ tự cài vào AppData\Local\Programs\LinhScript.

3

Chạy mã nguồn .hql

Mở Terminal / CMD ở thư mục bất kỳ và gõ lệnh:

LinhScript hello_world.hql

Tích hợp sẵn 28 thư viện lõi

Chỉ cần gọi use hql.<tên>; là dùng được ngay mà không cần trình quản lý gói ngoài.

Web Server & HQLSP

hql.web, hql.net, hql.socket

Tạo web server, trang động .hqlsp, WebSocket và gọi API.

Cơ sở dữ liệu

hql.database, hql.env

Hỗ trợ SQL Server, MySQL, PostgreSQL, SQLite kèm Connection Pool.

Game 2D & Đồ họa

hql.game, hql.multiplayer

Vòng lặp 60FPS, sprite, bản đồ isometric, âm thanh và mạng đa người chơi.

Văn phòng & Báo cáo

hql.export, hql.chart, hql.mail

Xuất file Excel, Word, PDF có màu sắc, vẽ biểu đồ và gửi email SMTP.

Giao diện & Tự động hóa

hql.ui, hql.app, hql.pc

Tạo cửa sổ Swing, đóng gói web thành app Chromium, điều khiển phím/chuột.

Toán học & Bảo mật

hql.math, hql.crypto, hql.schedule

Thống kê, ma trận, mã hóa AES/RSA và lập lịch chạy tác vụ Cron.

Plugin chính thức cho IntelliJ IDEA

Hỗ trợ lập trình tệp .hql và tệp cấu hình môi trường .henv trực tiếp ngay trong IDE.

Plugin v1.0.0 • IntelliJ IDEA 2023.2 – 2026.x

Tô màu cú pháp chuẩn xác

Syntax & Semantic Highlighting

Phân biệt rõ từ khóa, biến, hằng số, hàm lõi, lớp kế thừa (class, extends) và comment dòng/khối.

Gợi ý mã nguồn thông minh

use hql.* & import Autocomplete

Tự động gợi ý danh sách 28 thư viện lõi, đường dẫn tệp import và các hàm/class công khai có ký hiệu @.

Điều hướng & Kiểm tra lỗi

Ctrl + Click & Real-time Lint

Giữ Ctrl + Click để nhảy thẳng tới tệp được import hoặc nơi khai báo biến/hàm; cảnh báo đỏ ngay khi sai cú pháp.

Chạy trực tiếp & Hỗ trợ .henv

Run Configuration & .henv File

Tạo dự án LinhScript mới, chạy tệp .hql chỉ với 1 nút bấm và hỗ trợ đầy đủ tệp cấu hình môi trường .henv.

1

Tải tệp Plugin (.zip)

Nhấn nút Tải Plugin 1.0.0 (.zip) ở trên để tải tệp LinhScriptPlugin-1.0.0.zip về máy (giữ nguyên định dạng .zip).

2

Cài đặt vào IntelliJ IDEA

Mở Settings (Ctrl + Alt + S) → Plugins → biểu tượng bánh răng (⚙️) → Install Plugin from Disk... và chọn tệp .zip vừa tải.

3

Khởi động lại IDE

Nhấn Restart IDE để áp dụng. Sau đó bạn có thể tạo mới tệp .hql, .henv hoặc chạy dự án ngay trong IntelliJ.
